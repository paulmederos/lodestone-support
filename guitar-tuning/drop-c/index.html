Drop C tuning

Drop C tuning is C G C F A D, from the thickest string to the thinnest: D standard with the 6th string dropped another whole step, to C.

It works like drop D, a whole step lower: the bottom three strings (C G C) make a one-finger power chord.

Tap a string above to hear its note, or turn on the mic: the string you're tuning lights up and glows brighter as you get close.

How to tune to Drop C

  1. Tune to D standard first (every string down a whole step).
  2. Then lower the 6th string one more whole step, until it rings an octave below the open 4th string (C).

Questions

How do I get from standard tuning to drop C?

Lower every string a whole step, then lower the 6th string one more whole step. You end up with C G C F A D.
